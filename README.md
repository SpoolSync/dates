# Dates

Part of Pixora. Birthdays and anniversaries (with ages, gift ideas and a gift budget) and renewals for passports, driver's licences, health cards, PR cards, plate stickers and insurance.

- Add to my calendar makes a calendar file: yearly dates repeat, birthdays remind a week ahead, renewals months ahead.
- Encrypted on the phone with the Pixora passcode before it syncs. Works offline.

Live: https://spoolsync.github.io/dates/
